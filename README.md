# 🏠 Airbnb Listings Analytics Dashboard

## About the Project
This project is an interactive Power BI dashboard built to analyze Airbnb listing data. The goal was to uncover insights into pricing, room types, and geographic distribution of listings across neighborhoods.

## Tools & Skills Used
* Power BI
* Data Cleaning
* Data Visualization
* Dashboard Design (Red & White Theme)

## Key Metrics Analyzed
* **Total Listings & Accommodations:** KPI cards showing total volume.
* **Price by Room Type:** A bar chart identifying which room types are most expensive.
* **Neighborhood Distribution:** A column chart and a map showing where listings are concentrated.
* **Interactive Filtering:** Added a Slicer to filter by neighborhood.
